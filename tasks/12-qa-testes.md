# 12 — QA e Testes

## Objetivo

Validar visual, acessibilidade e fluxos de contato/pedido após as alterações.

## Checklist
- Testes manuais: mobile (<700px) e desktop (>=700px)
- Rodar `pnpm run ts` e `pnpm run build` para checar TypeScript e build
- Verificar fluxo de contato (`Quero revender`) e download do catálogo
- Atualizar/rodar testes em `src/__tests__` se aplicável

## Critério de aceite
- Build OK e checklist aprovado manualmente
